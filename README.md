# LOOPULUS — Landing Page

Landing page inicial da Loopulus, pronta para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `loopulus`.
2. Envie `index.html`, `styles.css`, `README.md` e a pasta `assets`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha `main` e `/ (root)` e salve.

A imagem usada no hero está em `assets/camisetas-loopulus.png`.

> Antes do lançamento público, substitua `hello@loopulus.com` pelo e-mail real da marca e, se quiser, troque a imagem de mockup por uma foto definitiva da peça.
